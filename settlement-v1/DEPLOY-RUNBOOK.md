## 1. Pre-flight (no cost)

```sh
export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"
solana config set --url mainnet-beta \
  --keypair ~/.config/solana/aifinpay-solana-deploy-2026-08-31.json
solana balance                     # expect ~2.5 SOL
shasum -a 256 target/deploy/aifinpay_settlement_v1.so   # must match BUILD-EVIDENCE
ls ~/Library/LaunchAgents          # only known vendor plists (post-incident rule)
```

## 2. Deploy (tight max-len — cheapest correct option)

A fresh program id is generated by the deploy. `--max-len` = exact artifact
size: upgrades then need a fresh buffer each time, which is correct practice
once the authority is a multisig.

```sh
SO=target/deploy/aifinpay_settlement_v1.so
solana program deploy "$SO" \
  --max-len "$(wc -c < "$SO" | tr -d ' ')" \
  --with-compute-unit-price 10000
solana program show <NEW_PROGRAM_ID>     # record id, programdata, authority, slot
```

If the deploy is interrupted: `solana program close --buffers` recovers the
buffer rent to the deploy key; retry.

## 3. Initialize (still the deploy key — it IS the upgrade authority right now)

`initialize_config` only accepts the upgrade authority, and the program comes
up **paused**. Instruction: tag `0` + treasury(32) + usdc_mint(32) +
usdt_mint(32); accounts: authority(signer,w), config PDA(w), program id,
programdata, system program. Use `tools/` client (or the SDK once repointed).

Verify: config PDA exists, owner = program, `paused = true`, treasury/mints
byte-exact.

## 4. Hand over BEFORE unpausing

Order matters — admin first (needs the authority signature only while we hold
it cleanly), then the upgrade authority itself:

```sh
# 4a. set_admin -> Squads vault authority  (tag 2)
# 4b. upgrade authority -> Squads:
solana program set-upgrade-authority <NEW_PROGRAM_ID> \
  --new-upgrade-authority <SQUADS_AUTHORITY> \
  --skip-new-upgrade-authority-signer-check
solana program show <NEW_PROGRAM_ID>   # authority MUST print the Squads address
```

The deploy key is now powerless. Sweep its remaining balance (~1.23 SOL
refunded buffer) back to Dimitry, and never use it again.

## 5. Supervised E2E, then unpause

One paid test while STILL PAUSED must fail with error 7006 (verify the
negative case). Then Squads proposes `set_paused(false)` (tag 1, admin =
Squads), execute, and run ONE supervised payment per route:
AIFP-1 native (exact 99/1 split), AIFP-2 native (100/0), AIFP-1 `pay_token`
USDC. Verify each by reading the receipt PDA and balance deltas at the
transaction's slot — against the CHAIN, not logs.
